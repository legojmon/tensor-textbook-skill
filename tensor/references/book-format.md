# Tensor 책 형식 (구조 · 쪽 순서 · 부품 · 그림)

수능 개념서식 구성(교과서 개념 → 수능 개념 2단 구조, 기출 연결, 개념진단)을 대학 과목으로 옮긴 형식이다.
CSS 는 `assets/tensor.css`(+ 흑백 `theme-mono.css`), 쪽 나눔은 `assets/paginate.js`, HTML 조립은 `scripts/build.py` 가 한다. **원고는 `references/manuscript-schema.md` 형식의 JSON 으로만 쓴다.** 이 문서는 책이 어떤 쪽과 부품으로 이루어지는지, 그림을 어떻게 준비하는지를 정한다.

---

## 1. 책 구조

과목 1개 = 상·하 2권.

| 권 | Part | 입력 | 내용 |
|---|---|---|---|
| 상 | Part1 「원서 개념의 정리」 | 원서 본문 + 강의록 | 원서 개념·원서 간접 개념, 원서적 해법만 |
| 하 | Part2 「시험 개념의 완성」 | 원서 예제·연습문제 + 강의록 예제 | 시험 개념, 원서적 → 시험적 해법 |

사용자가 한 장만 원하면 그 장의 Part2(또는 요청한 Part)만 만든다. 원서 1장 = Chapter 1개, 장 번호는 주교재의 번호를 그대로 쓴다. 보조 교재의 장 번호는 출처에 책 이름을 붙여 적는다(`보조 Listing 5.3`).

---

## 2. 쪽 순서 (Part2 한 장 기준) — build.py 가 이 순서로 만든다

1. **Chapter 표지** — 장 번호·제목·영문 제목, 하단 안내문(고정 문장 + `cover_note`)
2. **Chapter 목차** — Preview / `plan` 의 TOPIC 전부(안 만든 TOPIC 은 —) / A·01, B·01 / Review / 빠른 정답. 쪽 번호 자동
3. **Preview** — PRE-VIEW 박스: `preview.paragraphs` 3문단 → 〈학습 방법〉 ①~⑤(고정 문장) → MEMO
4. **강의 선정 문제** — 쪽당 2문제, `L·01…` (강의에서 다룬 원서 예제·연습문제)
5. **TOPIC nn** × 6~12 — TOPIC당 보통 3~6쪽, 자동 쪽 나눔
6. **TOPIC 적용문제 (A)** — 쪽당 2문제, TOPIC마다 1개 이상
7. **연습문제 (B)** — 쪽당 2문제 (원서 장 끝 Problems 선별, 4개 이상)
8. **Review: 개념진단** — OVER-VIEW 2문단 + TOPIC별 O/X 표(TOPIC 의 `ox`, 넘치면 다음 쪽으로 이어짐)
9. **빠른 정답** — 모든 L·EX·A·B 의 답 (`answers`)

쪽 번호: 짝수쪽은 왼쪽 아래(쪽번호 | 장 이름), 홀수쪽은 오른쪽 아래(TOPIC 이름 | 쪽번호). 홀수쪽 오른쪽 위에 `Part2` 탭과 `TOPIC nn` 탭. 문제 머리(번호·난이도 3칸·풀이 기록칸·출처·PAGE·TOPIC)와 힌트 줄은 자동이다.

## 3. 자동 쪽 나눔 (paginate.js)

- TOPIC마다 첫 쪽에 장 띠 + TOPIC 제목, 이어지는 쪽에 가는 윗줄.
- 블록이 넘치면 다음 쪽으로. **해법 박스는 단계 단위로 쪼개** 다음 쪽에 라벨 없이 이어 붙인다.
- 소절 제목과 `keep_next` 문단은 다음 블록과 같은 쪽으로 따라간다.
- 각주(`fn`)는 참조 블록이 놓인 쪽 아래로 가고, 자리가 없으면 참조 블록과 함께 다음 쪽으로 간다.
- `{"type": "pagebreak"}` = 강제 쪽 넘김.
- 고정 쪽(표지·목차·Preview·문제 쪽)은 자동으로 넘기지 않는다. Preview 는 한 쪽 분량(3문단)으로 쓴다. 넘치면 `render.py --strict` 가 `[넘침]` 을 낸다.

## 4. 부품 카탈로그 (TOPIC 안, 위에서 아래 순서)

| 부품 | 모양 | 원고 |
|---|---|---|
| TOPIC 머리 | 장 띠 + `TOPIC 01 제목` | `no`, `title` |
| 소절 제목 | 포인트색 굵은 글 | `"## 1. …"` |
| 흐름 칩 | 칩 → 칩 → 강조 칩, 아래 역방향 화살표 | `flow` |
| EX | 둥근 배지 `EX 01` + 출처 + 지문(왼쪽) + 그림(오른쪽) | `ex` |
| 원서적 해법 | 회색 박스, ①②③ 단계 | `sol` kind book |
| 생각 말풍선 | 가운데 말풍선 | `bubble` |
| 시험적 해법 | 굵은 왼쪽 막대 박스, 맨 위 `적용 조건` | `sol` kind exam |
| 개념 박스 | 아이콘 + 제목 + 3탭(원서 개념 / 시험 개념 / 원서 간접 개념 중 하나 켜짐) + 표·절차 + `적용 조건` | `concept` kind exam / book / ind |
| 본문 속 개념 태그 | `원서 개념`(실선) `시험 개념`(반전) `원서 간접 개념`(점선) | `<span class="tg ws">`, `<span class="tg">`, `<span class="tg ind">` |
| CORE | `[조건] ⟹ [행동]` 한 줄 | `core` |
| 저자 TIP | 검정 탭 + 제목 + 회색 본문 | `tip` |
| 답안·채점 포인트 | 테두리 박스, 번호 목록 | `grade` |
| 강의 VS 연습문제 | 2열 표 (출처 / 출제 요소) | `vs` |
| 각주 | 쪽 아래 작은 글, ⓐⓑ | `fn` + 본문 `<sup class="pc">ⓐ</sup>` |
| 코드 | 고정폭 상자 | `code` |

문제 쪽(L / A / B): `per_page` 2(기본)는 한 쪽에 위·아래 2문제, 지문 왼쪽·그림 오른쪽, 나머지는 풀이 공간. 4는 짧은 계산 문제만 2×2.

## 5. 그림
- 회로 과목: `scripts/circuits.py` (schemdraw). 자주 쓰는 토폴로지 builder가 있다. 새 토폴로지는 `drawing()`, `out_terms()`, `save()` 로 직접.
- 그 외 과목: matplotlib(그래프·좌표·블록도·배열·트리) 또는 직접 쓴 SVG. 선 굵기 1.1pt, 글꼴 Noto Sans CJK KR 12pt, 강조는 `#6B3FD4` 하나(흑백은 굵은 검정).
- 그래프: `plot_response()`.
- 본문 그림 폭 52~62mm, 문제 쪽 그림 60~76mm. 시험적 해법용 "전원을 끈 회로"는 ACCENT 색으로 강조.
- 그림은 `work/fig/` 에 두고 원고에서 `fig/이름.svg` 로 참조한다. 빌더가 파일 존재를 확인한다.

## 6. 흑백 인쇄 (기본)
- `"theme": "mono"`(기본)이면 `tensor.css` 다음에 `theme-mono.css` 를 불러온다. 색 대신 **모양**으로 구분한다: 시험 개념 태그 = 검정 반전, 원서 개념 = 실선, 원서 간접 개념 = 점선 / 개념 박스 = 이중선·실선·점선 / 시험적 해법 = 굵은 왼쪽 막대, 원서적 해법 = 옅은 회색.
- 장·Part 표지의 보라색 면은 흑백에서 옅은 회색 바탕과 짙은 회색 표식으로 옮긴다. 장 번호·CHAPTER·Part 표기는 짙은 면에 흰 글씨, 제목·작은 안내문은 밝은 면에 짙은 글씨로 둔다. 본문 띠와 탭은 선으로 구분한다.
- 컬러로 뽑을 때만 `"theme": "color"` 로 빌드하고 `TENSOR_THEME=color` 로 그림을 다시 만든다.

## 7. 색 바꾸기 (컬러 인쇄일 때)
`tensor.css` 맨 위 `:root` 의 `--p`(포인트), `--pl`(옅은 배경), `--pm`(중간), `--pd`(진한) 4개만 바꾸고, `circuits.py` 의 `ACCENT` 를 같은 값으로 바꾼다.
