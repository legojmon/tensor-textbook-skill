# Tensor 내용 규칙

교재의 품질은 "무엇을 쓰느냐"에서 갈린다. 과목과 무관하게 적용한다(예시는 회로이론이 많지만 방식은 같다). 이 문서는 개념 분류, 시험 개념 추출, 문제 고르기, 해법 쓰기, 문체, 검증 규칙을 정한다.

---

## 1. 출발점: 왜 원서와 다른 책이 필요한가

원서는 모든 내용을 같은 무게로, **개념 → 문제** 방향으로 쓴다. 시험장에서 필요한 것은 반대 방향, 즉 **문제를 보는 순간 무엇을 의심하고 어떤 개념을 꺼낼지**이다. Tensor는 원서를 다시 쓰는 책이 아니라, 원서를 **읽는 순서와 각 내용의 무게**를 시험 기준으로 바꾸는 책이다.

삭제 테스트 — 모든 페이지에 적용한다.
> 이 페이지를 지웠을 때 원서 해당 쪽을 펴면 똑같이 복구되는가? → 그렇다면 삭제하거나 다시 쓴다.

그래서 TOPIC 하나에는 아래 중 **최소 하나**가 반드시 있어야 한다.
1. 발상 질문 (생각 말풍선, "~를 의심한다")
2. 시험 개념 + 원서 개념에서의 유도
3. 원서적 해법 vs 시험적 해법 비교
4. 다른 장과의 연결

---

## 2. 개념 3분류 (개념 박스 상단 3탭)

| 분류 | 정의 | 판정 방법 |
|---|---|---|
| **원서 개념** | 원서 본문·강의록에 정의/정리/공식으로 있는 것 | 원서 본문의 박스·정리·굵은 정의, 또는 강의 슬라이드 제목급 내용 |
| **원서 간접 개념** | 원서 안에 있지만 본문 정리가 아닌 것 — 예제 풀이 속 요령, 연습문제 힌트, 각주, 부록, 앞 장·선수과목 내용 | 원서 어딘가에 있으나 본문 정리는 아님 |
| **시험 개념** | 원서·강의록 본문엔 없지만 **예제·연습문제에서 반복되는** 도구·관점·지름길 | 원서 본문/색인/강의록에서 찾을 수 없고, 문제 **2개 이상**에서 같은 생각이 결정적 |

시험 개념은 반드시 **원서 개념으로 유도**할 수 있어야 한다. 유도가 길면 본문에 ⓐⓑ 각주를 달고 해설에 싣는다. 유도할 수 없는 "요령"은 싣지 않는다.

---

## 3. 시험 개념 추출 절차

1. 원서 해당 장의 **예제(Example)·연습(Exercise)·장 끝 문제(Problems)** 를 전부 훑는다. 해설집이 있으면 같이 본다.
2. 문제마다 "이 문제를 빨리 풀게 해 주는 **결정적 관찰** 한 줄"을 적는다.
   (예: "응답식이 주어졌으니 상수=최종값, 지수=1/τ 로 바로 읽는다")
3. 같은 관찰이 2개 이상 문제에서 나오면 묶는다 → 후보.
4. 후보마다 원서 본문·강의록을 검색한다. 본문에 정리로 있으면 원서 개념, 예제 속에만 있으면 원서 간접 개념, 어디에도 없으면 **시험 개념**.
5. 강의에서 다룬 예제가 포함된 후보, 반복 횟수가 많은 후보 순으로 TOPIC을 정한다.
6. TOPIC 제목은 **행동형 짧은 구**로 쓴다. ("응답식에서 회로 읽기", "분모는 전원을 끄고 본다", "최종값 정리를 믿기 전에")

과목별 "결정적 관찰" 예시
| 과목 | 예 |
|---|---|
| 회로이론 | "응답식이 주어졌으니 상수=최종값, 지수=1/τ 로 읽는다" |
| 신호및시스템 | "입력이 계단이면 출력은 임펄스 응답의 적분 — 컨볼루션을 하지 않는다" |
| 미적분학 | "극한 안에 a^n − b^n 꼴이 보이면 인수분해 대신 평균값 정리" |
| 일반물리 | "충돌 직후만 묻는다 → 에너지 말고 운동량부터" |
| 확률·통계 | "'적어도 하나'는 여사건부터" |
| 경제원론 | "탄력성 문제는 중간점 공식 대신 비율 변화로 부호부터 정한다" |

한 장에 TOPIC은 보통 6~12개. 장의 첫 TOPIC은 강의 예제가 가장 많이 걸린 시험 개념으로 한다.

## 4. 문제 출처와 번호

강의록에 나오는 예제는 대부분 **원서의 예제·연습문제를 그대로 옮긴 것**이다. 그래서 별도 족보가 없어도 된다. 규칙:

- 강의록 예제는 먼저 **원서 번호를 찾아 대응**시킨다(예: 강의록 p.12 "Ex 14.7-1" = 원서 Example 14.7-1).
- 출처 표기는 **원서 번호 우선, 강의록 쪽은 보조**: `[원서 Example 14.7-1 · 강의 p.12]`
- 원서에서 대응을 못 찾은 강의 문제만 `[강의 p.N]` 단독 표기.

| 교재 칸 | 넣는 문제 | 번호 |
|---|---|---|
| 워밍업 문제 (장 첫머리) | 강의에서 다룬 원서 예제·연습문제. 문제마다 [준비] 칸에 정의·규칙 | `W·01` … |
| EX (본문) | 원서 예제 + 워밍업 문제 + 장 끝 문제 중 TOPIC 대표 문항 | `EX 01` … (TOPIC마다 새로) |
| 적용문제 (A) | 원서 Exercise/Practice + 자체 제작 변형 | 장마다 알파벳 1개 (예: A) |
| 연습문제 (B) | 원서 장 끝 Problems 중 선별 (원서가 둘이면 둘 다에서) | 장마다 알파벳 1개 (예: B) |
| 실전 문제 (장 끝) | 시험 형식 그대로: T/F·단답 → 손추적 → 손코딩. 강의 랩 함정, 시험 복기 유형 | `X·01` … `X·05` |

- 같은 문제가 워밍업 문제와 EX에 **중복으로 실리는 것은 정상**이다(장 첫머리에서 먼저 풀어보고, 본문에서 해부).
- 워밍업의 [준비] 칸은 정의·인덱스 규칙·연산 규칙만 쓴다. 답이나 풀이 순서를 쓰지 않는다.
- 강의 랩·실습 자료는 "강의 랩 노트"(원서 간접 개념 박스)로 본문에 넣는다: 측정 수치, 흔한 구현 실수, 슬라이드 정정.
- 문제 헤더 메타: 난이도 3칸 / 풀이 기록칸(1회·2회) / PAGE(관련 본문 쪽) / TOPIC(관련 TOPIC) / 출처.
- 정답률 데이터가 없으므로 정답률 바 대신 **풀이 기록칸**을 쓴다.

## 5. 해법 두 층

| 라벨 | 규칙 |
|---|---|
| **원서적 해법** (회색 박스) | 원서 개념만으로, 원서 방식 그대로. **항상 먼저**. 계산을 생략하지 않는다 |
| **시험적 해법** (보라 박스) | 시험 개념으로 빠르게. 원서적 해법 **다음에만**. 원서적 해법보다 확실히 짧아야 실을 가치가 있다 |

EX 하나의 표준 흐름:

```
도입 문단 (원서 개념 상기, 왜 이 유형이 중요한가 — 강의·연습문제 근거 번호)
→ EX (문제 + 그림)
→ 원서적 해법
→ "그런데 실제로 답을 정한 정보는 무엇이었나" 관찰 문단
→ 생각 말풍선 (학생 속마음 한 문장)
→ 시험적 해법
→ 원서 개념으로 논증 (왜 성립하는가)
→ 시험 개념 박스 → CORE 한 줄
→ (필요하면) 저자 TIP
→ 답안·채점 포인트
→ 강의 vs 연습문제 표 (출제 요소가 어떻게 변형되는가)
```

같은 TOPIC의 두 번째 EX부터는 원서적 해법을 생략하고 시험적 해법만 보여줘도 된다.

## 6. 대학 시험 특화 장치

대학 시험은 서술형 **부분점수**로 채점된다. 그래서 수능식 구성에 아래를 더한다.

- **답안·채점 포인트 박스**: 이 유형의 답안을 어떤 순서로, 한 줄에 무엇을 써야 점수가 되는지. 단위, 가정 명시, 유일해가 없을 때 선택한 값 명시 등.
- 강의록에 채점 기준(배점, 감점 규칙)이 있으면 **그 기준을 근거로** 쓴다. 없으면 일반 원칙만 쓴다.
- **강의 vs 연습문제 표**: 강의 예제 → 원서 연습문제로 갈수록 무엇이 변형되는지(그래프로 주기, 2차로 확장, 종속전원 섞기 …). 시험 변형 예상의 근거.

---

## 7. 공부법 시리즈 (최소화)

공부 방법론 페이지는 **기본적으로 넣지 않는다.**
- Part 앞의 **가이드라인 1쪽**(누가, 목표, "메인은 원서 개념")만 둔다.
- 챕터 안의 Method 페이지, 목차의 "공부법 시리즈" 칸은 사용자가 요청할 때만 만든다.
- 방법론적 조언이 필요하면 TOPIC 안의 **저자 TIP** 한 개로 대신한다(챕터당 2~3개 이하).

## 8. 문체

- 강의체 평서문("~이다", "~해 보자"). 독자는 Part1(원서 개념)을 마친 학생.
- 문단은 짧게(3~4문장). 한 문단에 주장 하나.
- 도입 문단에는 **근거 번호**를 쓴다: "강의 예제 Ex 14.7-1, 14.7-2와 원서 P14.7-1·2·6이 모두 이 구조다."
- 말풍선은 학생의 속마음 한 문장 ("응답식을 다 줬는데… 이걸 또 s영역으로 풀어야 해?").
- 수식은 KaTeX(`$…$`, `$$…$$`). 단위는 정자체: `$12\ \text{V}$`, `1.25 F`.
- 분수는 진짜 분수로 쓴다. 표 칸에서는 `$\displaystyle\frac{n-1}{2}$`, 본문 줄 안에서는 `\tfrac`(줄 간격이 벌어지는 `\dfrac`은 줄 안에 쓰지 않는다). `n/2`처럼 빗금으로 쓰는 것은 코드 조각뿐이다.
- 원서 문장을 번역해 옮기지 않는다. 문제 지문은 의미를 유지해 한국어로 다시 쓴다.

## 9. 검증 (출력 전에 반드시)

1. **모든 답을 sympy로 계산**해 확인한다(역변환, 부분분수, 소자 값). 원서/해설집 답과도 대조한다.
2. 회로도는 원서 그림을 보고 schemdraw로 다시 그린 뒤, **PNG로 띄워 직접 본다**(라벨 겹침, 스위치 방향, 극성).
3. `render.py --png` 로 렌더링하고 **[넘침] 경고가 0개**가 될 때까지 쪽 나눔을 조정한다.
4. 미리보기 PNG를 몇 장 직접 열어 박스·수식·그림 배치를 확인한다.
5. 강의 슬라이드·강의 코드·원서가 서로 다른 규칙을 쓰는 곳(삭제 규칙, 높이 규약, 비교 연산자 `<`/`≤`에 따른 안정성, 피벗 위치)을 찾아 본문에 어느 쪽을 따랐는지 적는다. 원서 부록 정답도 시뮬레이션으로 다시 확인하고, 틀리면 해설에 정정한다.

## 10. 저작권

- 생성물은 **사용자 개인 학습용**이다. 원서·강의록 PDF는 사용자가 직접 제공한 것만 쓴다.
- 원서 그림을 이미지로 잘라 붙이지 않는다(다시 그린다). 원서 문장을 길게 옮기지 않는다.
- 결과 PDF에는 원서·강의 출처 번호를 남기고, 공개 배포용이 아님을 사용자에게 알려준다.
