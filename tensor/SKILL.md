# Tensor — 강의록 + 원서 PDF → 시험 특화 교재

**입력은 두 개면 충분하다: 강의록 PDF, 원서 PDF.** (해설집·채점 기준이 있으면 더 좋다.)
출력은 바로 제본할 수 있는 A4 PDF다. 품질 기준은 `references/example-manuscript.html`(데모 원고)과 같은 밀도·구성이다.

## 먼저 읽을 것
1. `references/content-rules.md` — 개념 3분류, 시험 개념 추출, 문제 출처, 해법 두 층, 채점 포인트, 문체, 검증 **(필독)**
2. `references/book-format.md` — 책 구조, 페이지 순서, HTML 부품 카탈로그, 자동 쪽 나눔 규칙
3. `references/example-manuscript.html` — **완성 원고 예시.** 문단 길이·부품 순서·말투를 이것에 맞춘다

## 파이프라인

### 0. 준비 (처음 한 번)
```bash
bash <skill>/scripts/setup.sh
```

### 1. 입력 분석 — 자동
```bash
python3 <skill>/scripts/extract.py --lecture 강의록.pdf --textbook 원서.pdf [--solutions 해설집.pdf] --out work/
```
- 장 번호는 강의록 첫 쪽에서 자동 추정한다(`CH. 14` 등). 못 찾으면 사용자에게 묻거나 `--chapter`.
- `work/INVENTORY.md` 를 읽는다: 원서 장 범위, 절 목록, 예제·연습·장 끝 문제 번호와 쪽, **강의 예제 ↔ 원서 번호 대응표**.
- `work/lecture/sheet_*.png` 를 **전부** 본다(수식·회로는 텍스트 추출이 깨진다). 대응표에 빠진 강의 예제는 수치·그림을 원서와 비교해 직접 짝짓는다.
- 강의록 뒤쪽에 채점 기준(배점·감점)이 있으면 적어 둔다 → 채점 포인트의 근거.

### 2. TOPIC 설계
- `content-rules.md` §3 절차로 장 끝 문제를 훑어 "결정적 관찰"을 적고, 2개 이상 반복되는 것을 **시험 개념**으로 묶는다.
- TOPIC 6~12개, 첫 TOPIC은 강의 예제가 가장 많이 걸린 시험 개념.
- 범위가 "장 전체"면 TOPIC 목록을 사용자에게 한 번 보여주고 진행한다. "시안/TOPIC 1개"면 바로 진행한다.

### 3. 문제 고르기
- **강의 선정 문제(L)**: 강의에서 푼 원서 예제·문제 4개 안팎. 출처 `[원서 Example 14.7-1 · 강의 p.12]`
- **EX**: TOPIC마다 2~3개. 첫 EX는 강의 선정 문제와 겹쳐도 된다.
- **적용문제(A)**: 원서 Exercise/Practice + 같은 구조의 장 끝 문제 4개.
- **연습문제(B)**: 장 끝 문제 중 TOPIC을 고르게 덮는 것.
- 각 문제의 답을 원서 답(Answer:)·해설집과 대조할 수 있게 번호를 기록한다.

### 4. 그림
- `work/textbook/p*.png` 에서 원서 그림을 보고 `scripts/circuits.py` 로 **다시 그린다**(자르기 금지).
- 그린 SVG를 PNG로 띄워 직접 확인: 라벨 겹침, 스위치 동작(t=0에 열림/닫힘), 극성, 출력 단자.
- 시험적 해법용 "전원을 끈 회로"는 `dead=True`(강조색).

### 5. 원고 쓰기
- `assets/template.html` 을 `work/book.html` 로 복사해 채운다.
- 고정 쪽(표지·목차·Preview·문제 쪽·Review)은 `<section class="page">` 로, **TOPIC 본문은 `<article class="manuscript">` 안에 블록을 순서대로** 쓴다. 쪽 나눔·해법 박스 이어 붙이기·각주 위치·쪽번호·탭·꼬리말·목차 쪽번호는 `paginate.js` 가 자동 처리한다.
- 문단·부품 순서와 분량은 `example-manuscript.html` 을 따른다.

### 6. 검증
- 모든 답을 **sympy로 계산**하고 원서 Answer/해설집과 대조한다. 하나라도 다르면 원인을 찾을 때까지 싣지 않는다.

### 7. 렌더링·검수
```bash
python3 <skill>/scripts/render.py work/book.html --png work/preview/
```
- `[넘침]` 경고 0개, 콘솔 경고 없음.
- 미리보기 PNG를 **전부 열어** 아래 체크리스트로 검수하고, 고칠 것이 있으면 고친 뒤 다시 렌더링.

### 8. 전달
PDF를 보내고 짧게: 만든 범위, TOPIC 목록, 검증한 답 개수, 다음 단계 제안. "원서·강의 자료 기반이므로 개인 학습용" 한 줄.

## 품질 체크리스트 (시안 수준의 기준)
- [ ] TOPIC 첫 EX에 **원서적 해법 → 관찰 문단 → 말풍선 → 시험적 해법 → 원서 개념 논증** 이 모두 있다
- [ ] 시험 개념 박스 + CORE 한 줄 + 답안·채점 포인트 + 강의 vs 연습문제 표가 TOPIC마다 있다
- [ ] 도입 문단에 근거 번호(강의 예제·원서 문제)가 있다
- [ ] 모든 문제에 출처, 난이도, PAGE/TOPIC 링크가 있다
- [ ] 회로도 라벨이 겹치지 않고 원서와 토폴로지가 같다
- [ ] 수식이 깨지지 않았다(빨간 KaTeX 오류 없음)
- [ ] 공부법(Method) 페이지가 없다 (사용자가 요청한 경우 제외)
- [ ] 원서 문장을 그대로 옮긴 곳이 없다
