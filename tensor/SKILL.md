# Tensor — 대학 과목 시험 특화 교재 생성기

강의록과 원서를 넣으면, 원서를 **시험 기준으로 다시 읽게 해 주는** 인쇄용 개념서를 만든다.
핵심 가치: **"개념을 읽고 나면 강의·원서 문제를 전부 풀 수 있다."**

## 시작하기 전에 읽을 것
1. `references/content-rules.md` — 개념 3분류, 시험 개념 추출, 문제 출처, 해법 두 층, 채점 포인트, 문체, 검증 (**필독**)
2. `references/book-format.md` — 책 구조, 페이지 순서, HTML 부품 카탈로그
3. `assets/template.html` — 빈 틀 (복사해서 채운다)

## 입력 확인
- **필수**: 강의록 PDF(해당 장), 원서 PDF(해당 장이 들어 있는 것)
- 선택: 원서 해설집(Solutions Manual), 교수님 채점 기준이 담긴 풀이, 과거 시험
- 사용자 지정: 과목명, 장 번호, 범위(장 전체 / TOPIC 1개 시안), Part(기본 Part2), 포인트색(기본 보라)
- 빠진 필수 입력이 있으면 그것만 짧게 묻는다. 나머지는 기본값으로 진행한다.

## 작업 순서
1. **환경 준비** (처음 한 번): `bash <skill>/scripts/setup.sh`
2. **자료 읽기**
   - PDF 텍스트 추출(pymupdf). 수식·그림이 많은 쪽은 이미지로 띄워서 직접 본다(스캔본이면 전부 이미지로).
   - 원서 해당 장의 절 목록, Example/Exercise 번호, 장 끝 Problems 번호를 표로 정리한다.
   - 강의록의 각 예제가 **원서 몇 번인지 대응표**를 만든다. 강의록 예제는 대부분 원서 문제다.
3. **TOPIC 설계** — `content-rules.md` §3 절차로 시험 개념 후보를 뽑고 TOPIC 목록(6~12개)을 정한다. 장 전체를 만들 때는 이 목록을 사용자에게 먼저 보여주고 진행한다(시안 1개면 바로 진행).
4. **그림** — 원서 그림을 보고 `scripts/circuits.py`로 다시 그린다(회로 과목). 다른 과목은 matplotlib/SVG로. PNG로 띄워 겹침을 확인한다.
5. **원고 작성** — `template.html`을 작업 폴더에 복사해 쪽 단위로 채운다. 페이지는 고정 A4라 자동 넘김이 없으니 쪽마다 분량을 직접 나눈다.
6. **검증** — 모든 답을 sympy로 확인하고, 원서 해설·답과 대조한다.
7. **렌더링** — `python3 <skill>/scripts/render.py book.html --png preview/`
   - `[넘침]` 경고가 사라질 때까지 쪽 나눔 조정 → 다시 렌더링.
   - 미리보기 PNG 몇 장을 직접 열어 확인.
   - 브라우저가 없어 PDF가 안 되면 HTML을 그대로 주고 "브라우저에서 열어 A4로 PDF 저장"을 안내한다.
8. **전달** — PDF를 주고, 만든 TOPIC 목록·검증한 답·남은 결정(다음 장, Part1 등)을 짧게 알린다. 개인 학습용(배포 금지)임을 한 줄 덧붙인다.

## 기본값
- Part2, 장 번호 = 원서 장 번호, 포인트색 보라(`#6B3FD4`)
- 공부법(Method) 페이지는 **만들지 않는다**. Part 가이드라인 1쪽 + TOPIC 안의 TIP으로 대신한다.
- 정답률 대신 풀이 기록칸(1회·2회)
- 강의 선정 문제의 출처는 원서 번호 우선 `[원서 Example 14.7-1 · 강의 p.12]`

## 하지 말 것
- 원서 문장·그림을 그대로 옮겨 붙이기 (다시 쓰고 다시 그린다)
- 원서적 해법 없이 시험적 해법만 쓰기 (TOPIC의 첫 EX는 반드시 두 해법 모두)
- 유도할 수 없는 요령을 시험 개념으로 싣기
- 검증하지 않은 답 싣기
