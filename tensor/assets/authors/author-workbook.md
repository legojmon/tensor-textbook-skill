# 두 저자가 함께 쓰는 TENSOR 첫 원고

답은 메모체여도 좋다. 각자의 경험은 따로 쓰고, 서문은 두 답을 함께 읽은 뒤 고친다. 처음에는 아래 세 질문이면 충분하다.

1. 이 책을 만들고 싶었던 순간은 언제였나? 과목, 문제, 멈춘 지점, 그때 종이에 쓴 첫 줄을 떠올려 세 문장으로 쓴다.
2. 첫 독자가 같은 문제에서 무엇을 먼저 보았으면 하나? 그림이나 수식 한 군데를 짚고 이유를 한 문장으로 쓴다.
3. 두 사람이 한 권에서 지키려는 약속은 무엇인가? 독자가 실제로 펼쳐서 확인할 수 있는 예를 하나 붙인다.

## 각자 한 부씩 작성

| 쓸 것 | 답을 쓰는 요령 | 들어갈 곳 |
| --- | --- | --- |
| 이름·약력 | 한글명, 원하는 영문 표기, 공개할 소속이나 관련 경험 3~5줄. 책과 관련 있는 사실만 고른다. | 저자 소개, 표지·책등의 이름 |
| 막혔던 한 장면 | “___ 문제를 보고 ___부터 썼다. ___에서 막혔다. 다시 보니 ___가 주어져 있었다.” 실제 경험에 맞게 자유롭게 바꾼다. | 공동 서문의 도입 후보 |
| 독자에게 남길 말 | 옆에서 같은 문제를 푸는 후배에게 할 말 1~2문장. 두 사람의 문체를 각각 살린다. | 저자 소개, 선택적으로 뒷표지 |
| 사진 | 흑백으로 바꿔도 얼굴과 배경이 구별되는 상반신 사진 1장. 긴 변 1200px 이상 권장. 두 사진의 구도와 눈높이를 맞춘다. | 저자 소개 |
| 선택 자료 | 서명 이미지를 실으려면 흰 바탕에 검은 펜으로 쓴 사진 1장. | 서문 끝 |

**첫 번째 저자**

이름 / 영문 표기 / 약력 / 한 장면 / 독자에게 할 말 / 사진 파일명

**두 번째 저자**

이름 / 영문 표기 / 약력 / 한 장면 / 독자에게 할 말 / 사진 파일명

## 두 사람이 같이 정할 것

| 정할 것 | 적을 내용 | 들어갈 곳 |
| --- | --- | --- |
| 책을 펼칠 사람 | 어느 수업을 듣고 무엇까지 배운 독자인지 한 문장 | 서문 첫 문단, Part 가이드 |
| 이 과목에서 전할 것 | 3~5개. 각 항목에 주장 한 줄과 그 주장을 보여줄 예제 한 개 | ‘TENSOR에 대하여’, 뒷표지 |
| 공동 서문 | 두 장면 중 하나로 시작해 왜 책을 쓰는지, 첫 장을 어떻게 읽으면 좋을지 적는다. 감사 인사는 원하는 경우 덧붙인다. | 서문 |
| 저자 표기 | 표지·책등·저자 소개에 실을 이름 순서와 서명 형태 | 책 전체 |
| 시리즈와 학기 흐름 | 확정한 과목·Part와 진행 상태. 개강·시험 날짜는 확정된 값만 기입한다. | 커리큘럼, 학기 로드맵 |
| 선택 정보 | 정오 접수 창구, 실제 사용자의 게재 동의가 있는 후기, 발행일·판차 | 소통, 수기, 판권 |

## 원고 반영

저자별 이름·영문명·사진·약력·한마디·서명은 `authors.json`의 `name`, `name_en`, `photo`, `bio`, `message`, `signature`에 들어간다. 서문과 감사 인사는 `book.json`의 `preface`와 `thanks`, 핵심 메시지는 `about`에 넣는다. 뒷표지는 승인한 소개 원고에서 2~3문단을 골라 `cover.json`의 `back_paras`에 넣는다. 차례와 쪽수는 조판할 때 본문에서 계산한다.

사진과 작성한 답은 개인 작업 폴더에서 관리한다. 두 사람이 문구와 표기 순서를 확인한 뒤 인쇄용으로 확정한다.
