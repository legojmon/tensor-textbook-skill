# 회로이론및실습 공동 서문 초안

최재원과 김준형이 함께 검토할 제14장 견본이다. 서문과 뒷표지는 교재의 실제 예제를 바탕으로 작성한 편집 초안이다. 두 저자의 개인 경험·인용문·약력은 본인 원고를 받은 뒤 반영한다. 이름은 작업용으로 최재원 · 김준형 순으로 놓았다.

[서문·전체 차례·제14장 PDF](book.pdf) · [뒷표지 PDF](back.pdf) · [두 저자 작성지](../../tensor/assets/authors/author-workbook.md)

재원과 준형이 각각 작성지의 ‘막혔던 한 장면’과 ‘독자에게 남길 말’을 채우면, 두 장면 중 하나로 지금 서문의 첫 문단을 바꿀 수 있다. 과목과 시험 날짜를 확정하면 학기 로드맵의 각 단계에 날짜를 더한다.
